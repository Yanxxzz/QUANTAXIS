# 量价候选的数值稳定性

实现位于 [body_activity_pressure.py](../panda_alpha/body_activity_pressure.py)，测试位于 [test_body_activity_pressure.py](../tests/test_body_activity_pressure.py)。`native_code()` 导出同一组经过测试的函数和 Factor 适配器，远端代码不依赖本仓库安装。

## 两次独立发现

冻结预测保持五日等权实体均值减换手加权实体均值，方向、窗口、调仓和分组均不变：

`s = mean(e) - sum(e*T) / sum(T)`，其中 `e = (close-open)/(high-low)`。

原实现直接相减两个接近的均值。恒换手 0.1／10 或恒实体时，理论零被浮点残差转换成截面秩差。原代码和 413 日反例保留在私有研究归档。

第一版修复采用等价成对差分协方差和 `math.fsum`，通过了恒场与已有局部测试。真实 Skeptic 随后提出更强反例：

`e = [-1, -0.5, 0, 0.5, 1]`，`T = [1, 3, 2, 1, 2]`。

这组输入的 `sum(e)` 和 `sum(e*T)` 都精确为零，但乘积的浮点舍入仍使第一版得到约 `1.85e-18`。协调者实际复现后，两个应并列的证券被排成 1.0 和 0.5。首版因此停放，原通过记录、独立意见及新增失败证据全部保留；没有将实现失败登记为经济拒绝。

## 最终实现

有限的二进制浮点数可以精确表示为整数除以二的幂。函数把五个已经计算出的 `e` 和 `T` 分别转换到公共分母，再用整数计算均值差的分子：

`sum(E)*sum(W) - n*sum(E*W)`。

除以 `n*D_e*sum(W)` 后，只在返回浮点值时舍入一次。换手公共分母相消；整数中间结果避免先求均值或浮点乘积产生的消差误差。不设置裁零阈值，不按小数位取整，也不添加扰动。恒场和上述非恒场精确零均保留并列，另保留很小的真实非零效应。

本地实际验证包括：

- 原四组恒场输入各 413 个可计算日均无伪秩差；非恒场反例恢复为 0.75／0.75。
- 1,000 组独立 `Fraction` 参考与最终浮点输出精确一致。
- 当前 80 股外部输入上的顺序、前缀、缺失五日窗口、四档正单位缩放及本地接口重放。
- 自包含导出代码、无效权重、重复键和字段键不齐等 14 项回归。

其精确范围是**传入内核的二进制浮点实体和换手率**。OHLC 到实体的运算、输入本身的表示误差及最终浮点转换仍有舍入。单位换算也可能改变输入所表示的二进制数；已测样本的排名一致不代表任意浮点换算的普遍保证。
