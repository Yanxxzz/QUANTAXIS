## 本轮固定机制

在看新因子标签前登记两个定义，累计研究分母 466 → 468：

```
C = 本年销售商品及提供劳务收到现金 / 本年营业收入
    - 同版上年销售商品及提供劳务收到现金 / 同版上年营业收入

CQ01 = 同行业百分位(ARINV) × 同行业百分位(C)
现金单独对照 = 同行业百分位(C)
```

仅使用原 ARINV 当前选中的同版年度合并报告。报告身份、年度、原股票记录、收入绑定和 PDF 归档哈希一致；逐条核对 capture gzip、原提取文本 gzip 和解压内容哈希。收入复用已绑定的年度金额，不从旧 capture 字段重算。原 PDF 已清理，**本轮 PDF 原件核验为零**，文本验证不等于重新核验原件或完整 PIT 认证。

现金科目新增解析器 `panda_alpha/cash_collection.py`。它只接受明确的合并年度两列、金额、单位和年份，四列合并/公司混合表保持 pending。抽检茅台、隆基两组金额准确，美的四列未被猜填。销售收现率可能受增值税、预收/合同负债及票据或保理影响，不能直接解释为纯应收回款或库存变现。[证监局现金流说明](https://www.csrc.gov.cn/ningxia/c105510/c5293034/content.shtml)、[证监会相关审核意见](https://www.csrc.gov.cn/csrc/c100095/c1501269/content.shtml)。

6,470 个报告版本的留存文本全部复核，6,215 组金额可用；255 组保留 pending（191 组列/单位/期间待核、61 组科目行缺失或歧义、3 组合并表缺失或歧义）。没有下载或复制报告全文。每期现金样本 2,545—3,066 只，覆盖原共同样本约 95.68%—96.45%，相对固定身份约 48.46%—58.38%。缺失没有填零，也没有按未来行情可得性选择股票。

## 决策与保留

两个新定义均未通过预先冻结的 RankIC/五段稳定性/显著性筛查，未继续新增财富回放或官网派发。因此不存在本轮 CQ01 新净收益、净 Sharpe 或真实组合积分提升的结论，也没有将来源缺失标为经济失败。AR/INV 主线继续保留，现金字段及末段线索保留；不继续扫描本轮联合的权重、方向和窗口。

下一步优先是近季度公开财务更新及真实业务/现金变化解释。年度收现率的简单乘积尚未解决全窗口排序能力，应先补同版季度字段、发布时间和修订范围，再冻结新机制。原年度毛利单独对照仍有必要，防止把辅助因子的效果误归给 ARINV。
