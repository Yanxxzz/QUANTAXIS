# 因子池准入

2026-10-10 起的新审查使用 [pool-admission.v1.json](../config/pool-admission.v1.json)。准入评估的是实际因子池加入或替换后的结果。旧批次、门槛、失败记录和累计试验分母保持原样；这份政策不会启动研究、官网回测或因子池操作。

## 使用入口

沿用 `admission` CLI，不另建研究流程。示例配置的 `admission.policy_file` 指向新政策；`--policy` 可显式选择政策文件，优先于配置项。政策和证据须记录在结果中，保证知道是哪套规则作出的判断。

```powershell
python -m panda_alpha --config config/panda-alpha.local.json admission `
  --policy config/pool-admission.v1.json `
  --evidence research_runs/pool_admission_evidence.json `
  --output research_runs/admission_review.json
```

这是读取已存在证据的离线审查，不会自动采集、回测、收费、提交或删除因子。使用旧配置、旧证据接口得到的结果，不能自动换成新版合格结论。

## 两道门槛

第一道保留原通用质量要求：共同样本覆盖至少85%、至少200个调仓周期、方向一致的RankIC至少0.02、五折均为正、批次BH q不超过0.05；30bp/50bp净超额代理分别至少2%/0.25%，折收益25分位严格为正；每次调仓平均换手不超过15%。规模压力检验仍要求RankIC至少0.02、30bp净超额至少2%、50bp净超额严格为正；与实际池中因子的最大绝对相关不超过0.75。多重检验仍沿用真实累计试验数，不另起分母。

通用质量门槛核验新增或改动的候选。纯删除方案评估完整池及其合法过渡，不要求被删除的差因子反过来通过新因子准入门槛。

第二道检查完整池：30bp下净CAGR严格提高、净日收益Sharpe至少提高0.05；50bp下净CAGR不得下降；最近24个共同完整月份的复合净收益不得变差。历史A+C积分代理合计须至少提高5%，并检查近期窗口；这里的5%是相对于基线代理积分的增幅，不能写成NC提高0.05或Sharpe提高5%。基线代理积分为零时，百分比无法定义，应保留待核，不能用任意极小分母放大结果。

全窗回撤、最差月回撤、负收益月份或NC归零月份增加时，保留`risk_tradeoff_review`待核，不能仅凭全年Sharpe上升自动通过。已经由完整证据证明的收益或成本压力失败仍判拒绝；风险待核不掩盖它。

原配置中的单因子Sharpe≥2、优选2.5属于旧的特定付费研究目标，不是本政策的通用单因子硬门槛。高单因子Sharpe也不能替代组合增量；新版规则不追溯重判旧失败，也不复活人工淘汰方向。

通过相关性要求仍不代表获得独立信息。候选若嵌入已有因子，会改变这些轴在等权池中的隐含影响，必须与实际池重算；不能只说它是一个新的因子名称。

## 证据与重算

证据须绑定实际文件路径和SHA256，及候选定义、方向、池成员版本、研究日期、调仓周期、分组、成本和来源范围。相对证据路径按证据清单所在目录解析。文件缺失、哈希变化、池版本不匹配或数值无效，不能依靠 `status=verified`、`gain_positive=true` 等声明通过。

清单采用 `schema_version=1`，包含 `plan` 和 `artifacts`：

- `plan`：`as_of`、`window.start/end`、`cycle=5`、`groups=10`、`operation`（add/replace/remove）、`baseline`、`proposed`、`transitions`、`candidate_ids` 和 `planned_change_date`。成员包含 `id`、`version`、`definition_sha256`、`direction`、`effective`；每个过渡状态也是完整成员列表。
- `artifacts`：`contracts`、`quality`、`ledger`、`points`、`shadow`，每项均给出 `path`、`sha256`。文件正文包含 `status` 和 `plan_sha256`；计划摘要由排序键、紧凑分隔符的规范JSON计算SHA256。缺文件、缺哈希或仍绑定旧计划的证据保持待补。
- `contracts`：来源、PIT股票池、执行、官网迁移、当前池快照、独立日历、基准及组合构造的外部验收状态；`calendar_months`由独立来源审查给出每月完整交易日，另经该合同文件哈希绑定。合同声明不能替代真实来源或执行核验。
- `quality`：通用质量门槛对应的原始数字，而非一个预先写好的通过布尔值。多候选方案使用 `metrics_by_candidate`，键集必须与 `plan.candidate_ids`一致，逐支核验；单候选仍兼容 `metrics`。
- `ledger`：`type=pool_signal_daily_ledger`；`calendar_months`列出每月全部交易日，`benchmark`记录日期与日收益，`costs`按 `0.003`、`0.005`保存 `baseline`、`proposed` 日记录，每条有 `date`、`net_return`、`turnover`、`fee`。准入器由此重算净复利、Sharpe、回撤、近期表现与月度C。
- `points`：`months`逐月保存 `baseline`、`proposed` 的 `a_scores`、`decay`、`a_cap`，与重算C合成历史A+C代理；不能把历史记录伪装成正式B。
- `shadow`：冻结方案后前瞻影子验证的独立结果；本地通过时尚未验证的影子阶段不会被当作已完成。`calendar`必须原样等于 `contracts.calendar_months[shadow.month]`，且至少包含10个交易日；合同应同时绑定后续验证月份，不能把月内预览冒充完整月。每支新增候选至少有两条冻结后完成的影子IC记录，才可能进入最终人工审查阶段；全部冷启动只允许影子待验阶段，不宣称官方资格或积分。

`ledger.calendar_months`必须与独立合同中对应月份完全一致。完整月不能由账本自身的报价行数认证；缺失交易日不能靠把同一天从日历和收益记录同时删除来掩盖。前瞻影子期也沿用独立日历契约，不能临时采用影子账本自己列出的日期。

组合构建必须与比赛一致：每个因子按方向对齐，做1%–99%缩尾和Z-score，等权合成信号，按合成排序持有前10%股票。**平均单因子收益不等于这一组合。** 在相同形成样本和交易日期，用真实持仓延续、现金、交易成本及交易限制重算基线和拟调整池的日账本；不能用未来行情是否齐全筛掉形成时可选股票。

逐个删除、逐个新增可用于归因，但最终要审查完整拟实施方案。两支单独有益，不保证同时替换也有益。当前池、每个生效过渡状态和最终池都必须有至少5支合规有效因子，且不超过50支。不能只数注册对象而忽略尚未生效、失效或无信号的因子。

年度算术平均收益、官网未扣费的分组周期统计、单因子组收益不能替代扣费后的复合池净值。日线潜在成交证据必须注明其范围，不冒称实际竞价成交或容量已核验。

## 月度积分与B冷启动

历史积分代理按每个共同完整自然月计算，不把整个研究窗口合并后计一次分。Rex采用相对财富年化：`((1+Rp)/(1+Rb))**(252/N)-1`，基准应是官方中证全指；其他基准只作明确标注的研究代理。旧参考材料另有“分别年化相减”口径，正式结算仍以平台最新确认值为准，不能在两种公式间挑选有利结果。

SR使用扣费后的**绝对组合日收益**，不是日超额收益。月换手取各统一调仓日换手之和，评分分母下限为30%；低于30%再降换手，只可能通过省费改善收益，不能再缩小评分分母。`rawC`为负时NC为0，达到0.6时NC饱和为1。先完成每月截断再汇总，不能先平均rawC再截断。月初只重置评分净值起点，跨月持仓继续；不能虚拟清仓并重复扣费。

A和B是单因子质量的算术平均，增加因子可能稀释均值。B只认该版本正式生效后完成的持有周期，历史回测与近期历史留出均不能冒称正式B；代码或公式新版本重新累计的影响也需记录。新因子B冷启动时要审查积分损失，但平台B分母究竟包含全部有效成员还是仅满足B条件的成员，未核实就保持 `pending`，不能默认为一种实现。

基线和拟调整池中未改版本的共享因子，在同一月份必须使用相同原始A/B记录、分数及衰减和封顶设置。不能靠提高旧成员的分数、改变口径或改变衰减/封顶制造新增因子的积分贡献。

历史A+C改善属于研究代理，不代表完整的A+B+C官网积分增量。没有新增后的官方月账本时，可以做保守的冷启动与压力分析，不强迫尚未入池的候选先拥有入池后的官方历史，避免无法完成的循环条件；同样不能凭代理宣称已赚取官网积分。

## 审查结果

- `pending`：来源、PIT、实际池、执行、窗口或评分口径等证据不足，说明缺什么；来源缺失不判经济失败。
- `rejected`：完整且绑定的证据显示违反门槛，记录具体数值和原因；不能用其他缺件掩盖已证实的失败。
- `ready_for_shadow_validation`：本地质量与完整池代理通过，可以冻结版本做影子验证；官网积分提升仍未证实。
- `eligible_for_review`：所需生产可复现性、方向、来源及执行证据已齐，可提交人工审查；仍不是自动入池，也不是未来收益保证。

本地通过不要求候选已经积累入池后的官方B或月积分，但这部分缺失必须显式保留，`official_points_gain_verified`不能因此变为true。任何正式池操作和新的官网回测都由各自授权流程决定，准入政策本身不授权执行。

## 月度执行纪律

按已保存赛事规则，新增可随时提交；修改和删除仅在每月1–3日窗口，具体截止和生效时点以平台为准。先冻结下一窗口的完整方案和候补，不因某一天负收益不断改版本、清空B积累。

行业和市场风格报告用来提出机制假设、检验风险暴露及不同状态下的稳定性，不能代替质量和组合门槛。月度预测正确也不保证同风格因子赚钱；不按自然月名称机械轮动，不以部分当月收益反向调参。
