# 两连板急跌：增加行业与公告判断的初步检验

本次新增两条独立判断，规则分别事前冻结，随后计算完整样本；没有把多个条件叠加后挑最好结果。两条都已实现为纯函数。当前没有足够证据将它们加入正式选股或因子池。

## 样本与执行时钟

固定使用旧`base_mask`按日期、代码排序的前100次机会，覆盖2025-01-06至2025-02-12、64家公司。该mask已继承前20日涨幅有限且不超过18.5950413%及旧来源资格，**并非全部未筛选的两连板机会**。它们是候选挂单机会，不是100次实际成交，也不是原涨幅过滤账户的全部交易。复用已完成的22次触及跌停买价、未来5日标签完整事件，分布在9个日期；不重跑原账户或原1138个标签。本次补充核查明确了入口文字，旧100身份、分数与数值结果均不改。

所有新判断只使用挂单前已知的信息。未来是否触价及标签完整性只用于事后比较，不参与盘前筛选。该窗口此前已经使用，不能称为新样本外验证。

## 行业联动：检验“连板有同行响应更容易反弹”

采用已于2024-09-30公开的CAPCO 2024H1行业分类，不使用后来发布的分类。对挂单前两个交易日，计算同行业其他股票至少一次涨停收盘的比例，再减去固定研究股票范围内其他股票的同口径比例。目标股票从两个分母中剔除；至少需要5个可观测行业同伴及30个可观测全范围同伴。缺失行情、ST或生命周期不明不填成“没有涨停”。

事前方向是相对参与比例越高，反弹越好；自然筛选条件固定为分数大于0。它加入了外部行业身份和其他股票的信息，仍使用同行价格，不能称为纯非价格或真实资金流指标。

100次机会中99次有完整分数，22次可比较事件全部有支持：

- 相对行业参与为正的12次：平均5日毛收益 **+1.28%**；未来最低价相对买价的平均收益 **−8.76%**。
- 相对行业参与非正的10次：对应 **+3.90%**、**−4.80%**。
- 相同22次事件的未筛选均值为 **+2.47%**、**−6.96%**。
- 分数与5日收益的合并事件Spearman为 **−0.2583**；只有4个日期满足每日至少4个样本且分数、收益均非常数，日相关均值为 **−0.2845**。这不是正式独立五日RankIC序列。
- 按原双边30bp事件费用代理，正组平均 **+0.67%**，非正组 **+3.27%**，同支持基准 **+1.86%**。

这个小样本不支持预设的“相对行业热度高更好”方向。没有反转符号、改成过热因子，或改行业、窗口、门槛救回。日期重叠、同股重复与样本小都限制外推；结果不排除其他不同的行业信息机制。

## 公告判断：排除近期明确收到证券监管立案通知的标题暴露

独立检索巨潮公告元数据固定窗口2024-10-08至2025-02-11，“立案”关键词分页完整取得99条主窗口元数据；额外正对照仅验证检索路由，2026年的正对照公告不进入2025年信号。没有下载公告PDF或核验全文。

每次挂单只观察此前90个自然日、最晚前一天公开，并已到下一独立交易参考日的公告。标题须明确“证监会/证券监督管理委员会”“收到/被”“立案”，主体是公司或标题明确的关联方。进展、结案不算新的收到通知，也不推断案件已解除；语义不明保持未知。公司与股东、高管被立案不能混称为发行人自身违法。

本次只检验这种**新收到通知的标题观察**，没有重建完整在查案件状态。未命中仅表示在这次固定关键词查询中未观察到该类标题，不能据此称公司无风险，不能把未命中者认定为纯流动性错杀。

100次候选中98次未观察到该类标题，2次命中；2次命中机会均未触及跌停挂单价。实际22次可比较事件全在未命中组，筛选前后样本与收益完全一致，相关系数因常数而未定义。因此本样本**无法检验**公告门槛的反弹辨识力，不能说它有效或经济无效。

## 尚未测试的输入与结论

融资买入、偿还以及真实换手率可能提供不同于单股K线的信息，但当前没有把历史融资资格、数据单位、发布时间及换手分母绑定完整。旧融资接口曾有成功记录，不应说服务从未可用；本次没有新增这些数据的查询、因子或收益测试。

这两条试验提供的是选股条件的局部证据，**没有形成新策略净值、年化Sharpe、正式十分组、持续原生计算或入池证明**。5日事件均值、未来最低价收益也不能当作账户收益或最大回撤，更不能代表跌停排队必然成交。

本次官网调用及费用均为0，旧夜间预算未复用，旧自动化保持暂停。共新增4个登记context，含两个同支持对照，累计587=415历史+172唯一，不能解释为172条独立alpha。

实现：`panda_alpha/limit_sector_support.py`、`panda_alpha/limit_announcement_gate.py`。各自纯合成测试分别34项、8项通过；两个固定真实范围的本地执行均已完成。
