# 融资对照策略：止盈、止损与持仓期限（2026-10-15）

**四个固定退出版本、八条新成本路径全部完成。没有一个同时保留收益并明显降低回撤。止损和持仓期限解决了长期占仓，却损失了主要收益；降低止盈只能有限降低回撤，仍留下长期套牢头寸。**

以最近融资对照的共同1444个机会为基准，窗口2024-01-02至2026-09-18，659交易日。原基准两档结果直接复用，没有重跑。所有新版本在读取其收益前已冻结、登记，按完整区间统一评估；该区间已经暴露，不是独立样本外。

## 本轮规则

入场、股票范围、前期涨幅门槛、融资数据有效性、10万元初始资金、5仓各20%、100股手数及原成交量上限均不变，仍为两连板后预挂跌停价买单。只改变退出规则：

| 版本 | 止盈 | 止损 | 最长持仓退出 |
|---|---|---|---|
| 融资对照 | 严格超过10% | 无 | 无 |
| 提前止盈 | 严格超过5% | 无 | 无 |
| 固定止损 | 严格超过10% | 触及亏损8% | 无 |
| 时间退出 | 严格超过10% | 无 | t+20开盘尝试 |
| 三项合并 | 严格超过5% | 触及亏损8% | t+20开盘尝试 |

t是买入日；引擎将买入日计作第1个持仓交易日，因此t+20对应第21日开盘。T+1、一字跌停/停牌/容量阻挡均保留。止损跳空按更差的开盘价；同一日同时触及止盈止损而无法确定先后，按止损优先。已到期或已触发但无法卖出的指令持续等待执行，不能把20日或8%当成实际持仓/损失的硬上限。时间到期在开盘执行，优先于当日后续价格触碰。

每种机制仅一个固定设置，合并版本也在独立版本结果出现前定好。本轮预设研究参考为：在30/50bp下都保留至少80%基准累计净收益，并将最大回撤相对降低至少20%；这是比较参考，不替代正式因子入池条件。

## 收益损失来自哪里

已完整读取账户后，只用已有交易记录作同股票、同入场日的描述性对照，没有新增行情、信号或收益回放：

- 原基准49笔已平仓中，有18笔在t+20之后才平仓，贡献约54,868元净利润；其中11笔在t+60之后，贡献约30,999元。这只描述成功反弹的已平仓交易，原基准仍有5笔未平亏损仓，不能推断亏损仓都应继续等。
- 8%止损版与基准54个原始入场身份全部重合，其中23笔在基准中最终止盈的交易，被提前以亏损退出。释放槽位后另成交63笔，合计净亏约6854元。其117笔已平仓中，64笔止损合计−103,255元、53笔止盈合计+94,265元。
- t+20版本同样保留54个原始入场身份，其中16笔基准最终盈利的交易被提前亏损平仓。另成交47笔；45笔已平约+9838元，2笔期末浮亏约−4559元。新增机会没有补偿被截断的反弹收益。
- 5%止盈新增21个入场身份，其中18笔已平约+29,547元，3笔期末浮亏约−32,869元。退出更快仍可能换来新的长期亏损仓。

**基准的日净值本来就包含浮亏，因此差异不是简单把账面亏损改成已实现亏损。退出规则改变了后续反弹参与、资金规模和可成交机会。**上述匹配仍存在仓位金额和现金路径差异，不是独立因果估计，也不应据此挑选几个亏损代码排除。

8%止损版最差一次止损成交的费用前价格收益约−15.43%，说明隔夜跳空等执行时点使触发阈值不等于亏损封顶。该版本费用约12,215元，基准约9378元；成本增加是拖累之一，但无法单独解释近10万元的终值差距。

按预先固定的2000次配对自然月抽样，30bp下候选减基准的年化算术平均日收益差95%区间分别为：5%止盈[−22.99,+3.18]、8%止损[−55.62,−4.94]、t+20退出[−49.74,−0.94]、三项合并[−59.79,−5.18]个百分点。后三项在这个描述性方法下也呈现负差异；这不是CAGR差或经过多重试验校正的样本外证据。

## 数据、核对与结论

十条完整账户（八新、两旧复用）的日净值指标复算差小于4e-15，已实现/未实现损益对账差小于1e-6元。6项新的合成执行检查通过，既有引擎和旧测试没有修改或重跑。持仓计价均未中断，期末没有强行平仓。

各新版本保留一笔600008在2025-06-05的未成交待核买单：留存行情最高价3.21高于原参考价计算的涨停价3.19。旧基准也记录一笔来源待核买单，用旧交易和冻结名单可还原该日同一唯一候选。原价格、限制带、名单与不成交结果全部保留；没有补价或把未知成交填成成功。这一共用输入缺口、历史数据版本/公布时刻、总回报等价股数及日线排队假设仍限制实盘外推。

结论是保留原融资对照作为研究基准，四个固定退出版本均不升级。更短持仓和更低止盈已证实能释放部分槽位，但本次没有实现“保留收益并降低回撤”。后续若继续，需要研究能够区分短暂回撤与反弹失败的条件信息；本轮没有据结果反复调整5%/8%/20日，也没有宣称全部退出机制无效。
