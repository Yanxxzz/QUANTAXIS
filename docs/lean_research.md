# 精简研究流程

目标是找到可靠的好因子。模型负责提出和辨别机制；调度、算账、固定检查及结案交给既有程序。官网积分、RankIC 或 Sharpe 任何一项都不单独代替成本、确认检验与组合贡献。

## 默认路径

1. 一个主研究员提出最小可检验定义，登记机制、方向、窗口和失败条件。默认量价前沿探索；有可用财务输入时可以选基本面，不强制第二方向出提案。
2. 当前聊天协调器复用免费取数、数值/原生预检和 `study.prepare_study/evaluate_study` 生成输入。程序先筛固定定义，明确弱的候选直接停放，不反号救结果，不自动否定整个机制。
3. 本地入围，或有真实数据缺口且允许官网替代时，Skeptic 一次独立审设计和本地证据。不同意则停放；不强制挑战、作者答辩、跨线和 Lead 四次交接。
4. 宿主机械冻结批准的定义；官网仍检查预检、来源/PIT、真实余额、grant、累计研究轮和未结算 Run。数据缺口允许选择验证路径，不代表来源门槛通过。
5. 真实结果由 Skeptic 独立复核，宿主严格映射决定并幂等写科学记忆，不提升结论、清除待核项或自动入池。技术失败不当经济零值。

完整普通候选通常只用**提案、设计审查、结果复核三个模型动作**；本地停放只用提案，seed 不重复提案。已有跨线异议返回 `cross_line_disposition_required`，保留异议等待明确处置。复杂问题可另选旧四角色流程。

## 额度约束

新 [host](../config/team-host.example.json) 模板使用 `workflow=lean`、最多4轮/24宿主动作/**16次真实模型尝试**；[workers](../config/team-workers.example.json) 使用 `gpt-6.1-sol`，主研究员 high、审查 xhigh，每工作最多2次尝试。模板故意保留过期截止，需按新聊天授权填写，不自行启动研究。

- 所有首次、失败及重试在启动前共同占用 `model-budget.json`；满额返回 `model_session_budget`，重连不清零。已记录但启动不明的意图保守占额。
- 每角色每候选单独会话，同任务恢复复用原会话。作者与审查会话隔离，后续候选不带整晚历史聊天。
- 单次提示上限180KB，超限在调用前返回 `prompt_size_limit`。仅附当前任务和明确交叉对象；其他来源历史保留待核编号、修订、文本和状态索引。人工退休/经济失败约束及当前任务证据完整保留，原包不修改。
- 同时使用既有可逆重复内容编码。字节和调用下降不能换算为额度下降百分比；结束时用同一额度窗口的起止快照核算，不累加各 turn 的累计 token 数。

16次只约束该部署的 worker，不覆盖主聊天和其他聊天的共享额度。软件修复/新会话仍计入操作者原总体范围，不因新编号刷新预算。研究期间优先实验，无新材料就保存阻点并停止，不调用模型循环检查时间；默认不做无关工程。

## 本地输入交接

使用原 `host-init → service-prepare → host-control`。已准备的 seed 可绑定 `local_screen_config`。新提案生成后，协调器完成免费本地输入准备，沿原会话交接：

```text
python -m panda_alpha.team screen-bind --ledger DB --task ID --version N --input LOCAL_CONFIG.json
```

配置沿用[本地筛选](local_first_research.md)，`inputs[fingerprint]` 指向包含原指纹/请求哈希、数据可用性及证据的 manifest。只允许给尚未审查的 `proposed` 绑定一次，同内容重试幂等。输入改变或代码错误保留原件，按后继定义/有限修复流程处理，不覆盖旧报告。

`local_screen_required` 时服务只等待程序交接，不调用审查模型；原截止/停止开关有效。绑定后原 runtime 继续，不新开模型阶段或重置预算。缺输入不能伪造为不可得；算子不等价、损坏或哈希变化必须修复，不转收费回测。

旧 spec 缺少 `workflow` 时保持原四角色协议。旧终态、失败、两库、A/B 资格及官网额度不迁移、不复活。本次仅离线软件验收，研究仍停止，没有新模型或官网质量对照，不声称因子表现或实际额度比例已改善。
