# 两连板急跌：非单股K线信息的扩展数据检验

本轮按“补充数据，按照该思路进一步继续研究”推进。已完成公告来源缺口、完整连续机会范围及必要逐事件标签的补充，并核验真实换手率的单位。本次未取得显著改善证据，没有修改正式因子池。

## 固定完整范围，保留既有规则

从原100次机会扩至同一2025起点之后的全部 **2129次机会、1002只股票、408个形成日期**，截止2026-09-18。名单在新增公告数值和收益读取之前冻结，不按命中公告或亏损股票挑样本。它沿用旧`base_mask`，已经包括前20日涨幅有限且不超过18.5950413%及旧来源资格；并非全部未筛选的两连板机会。

公告条件完全沿用原版：挂单前90自然日内，最晚前一天已公开，并已到下一独立交易参考日的“公司或明确关联方收到证券监管立案通知”标题。进展不算新的收到通知，未知不填0。没有改变方向、窗口、标题类别、阈值或权重来适配结果。

2129次中 **2100次未观察到该类标题、18次命中、11次标题主体或语义未知**。未命中不是公司无风险；这条规则没有恢复全部在查案件、确认首次立案或违法事实，也没有认证历史修订/PIT。

## 扩展结果

2129次中，1899次明确未触及跌停挂单价，227次触价且未来5日标签完整，另3次标签未明。在227次中，1次公告语义未知，最终 **226次事件共同可比较**，分布于142个日期、207家公司。

预先定义的立案标题只覆盖其中 **1次**，其余17次命中候选都没有触及买价。这次是603825在2025-02-18的机会，事前元数据标题明确为“公司及实际控制人收到”立案告知书；不能混称为仅关联方，也不代表事件当天案件仍在查或违法已认定。这1次后续5日毛收益 **−12.48%**，未来最低价相对买价收益 **−12.61%**。单个事件不能证明公告风险的平均经济影响。

- 同支持未筛选的226次：平均5日毛收益 **−0.9465%**；平均未来最低价收益 **−8.6477%**。
- 排除该标题后的225次：对应 **−0.8953%**、**−8.6301%**。
- 按原双边30bp事件费用代理，均值从 **−1.5391%** 变为 **−1.4881%**，只改善 **0.0510个百分点（约5.10bp）**；50bp下也仍为负。
- 合并事件的二元分数Spearman约 **+0.0812**。每天有效横截面对比为0，因此正式日RankIC均值未定义；不得把合并相关当成正式因子RankIC。

旧100次中的22个可比事件平均毛收益为+2.47%，新增范围204个可比事件为−1.31%；完整同支持均值转负，原小样本的正均值未在扩展范围保持。新范围同样属于已暴露历史，仍不是新的样本外证据。

本轮不把这点均值改善称为显著收益提升，不反转公告或行业方向，不据唯一坏案例另拟阈值。狭窄立案标题过滤无法单独解决策略的收益与回撤问题；这也不等于所有公司信息、调查进展或不同资金机制都无效。

## 换手与融资输入的补充进展

固定原名单前4家公司、两板日期共8键，事前冻结来源及1%单位容差后，只读取既存换手率、成交股数与供应商流通股本。8/8同键有值，`(换手率/100)×流通股本/成交股数`介于0.999939至1.001224，最大偏离0.12244%。它支持该缓存采用**百分点与供应商流通股分母**，纠正了此前“分母完全没有依据”的过强说法；历史发布、修订/PIT和官网等价性仍未知。没有用这8个单位检查直接声称换手选股有效或低换手更好。

融资方面已找到公开SDK中`get_mtss`及按日期查询融资资格的`get_margincash_stocks`合同，补上了读取路径依据。当前账号免费权限、金额单位和实际历史发布/修订尚未核齐，本轮未调用融资数据，未假称融资筛选已经回测。行业正方向的旧不利结果保留，后续行业版本的完整身份核验仍有限，没有随公告扩域静默改变同行分母。
