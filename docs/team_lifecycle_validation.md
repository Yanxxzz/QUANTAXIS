## 聊天官网执行入口的离线验收

`service-prepare --execute --config` 冻结官网执行配置；`host-control start --execute` 才能显式启动该部署，stop/status 复用原入口。没有安装自启，没有启动真实角色或官网任务。

- 准备、状态和未显式执行的启动不访问账户；登录适配器不能启动官网部署。
- 正常停止、整个进程树丢失后恢复均沿用原 Run；模拟 create/start 各一次，结算一次，科学定义一次，原清单与累计限制保持不变。
- 恢复已有 Run 时允许只读结算暂停团队的作业；新派发仍被缺失/过期 grant、原生来源和财务 PIT 条件阻断。
