## 正文

我们在核验已有因子回测的可复现性，已查阅因子开发、因子分析、get_factor、get_fina_reports 及定期报告预披露文档。请协助提供以下官方说明或免费的只读核验方法：

1. Python Factor 接收的 close、turnover 序列是否包含请求开始日前的暖机数据？如何确认输入起始日、时区和数据可用时点？报告 IC/分组收益的日期标签分别表示信号形成日、持仓开始日还是收益结束日？
2. 已完成的 Run 能否导出原始逐形成日的有限值股票键、原始输入快照标识及实际 worker 版本？对照实验能否复用同一快照，并按两者共同有限值集合比较？如果不支持，请明确说明。
3. 回测环境中的 construction_in_progress、net_fixed_assets、total_assets 分别映射到哪些官方字段？是否分别等价于 bs_cip、bs_net_fix_assets、bs_total_assets？请确认单位、报告期、净额/合计，以及是否对三个输入选择同一报告期。
4. 历史财务数据按哪一个公告时间生效？如何处理补充公告、修订、重复记录和最新披露选择？get_fina_reports 的 date、is_latest、if_adjusted 与回测环境的历史 PIT 选择是否一致？能否给出一个带报告期、公告日期、修订版本和 available_at 的最小示例，并说明其与原 Run 的绑定方式？

请提供链接或可引用的说明；如某项只能付费获取，请先说明费用及权限范围，不代为启用。我们会保留未获证部分，不把接口更新时间或预披露首次发布日期当作财务值的历史可用时点。
