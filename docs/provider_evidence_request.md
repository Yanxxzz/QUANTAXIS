# 咨询：因子回测的输入日期、财务字段与历史数据口径

您好，我们想核对已有因子回测的数据口径，烦请协助确认以下问题。

## 一、需要确认的数据口径

1. **输入与暖机**：Python Factor 接收的 `close`、`turnover` 是否包含回测开始日前的历史数据？包含多少、如何确认最早输入日期？当天数据从什么时点可用于计算，采用哪个时区？
2. **报告日期与样本**：IC、分组收益的日期分别对应信号形成日、持仓开始日还是收益结束日？缺失或无效因子值的股票如何筛选？
3. **财务字段与报告期**：回测中使用的 `construction_in_progress`、`net_fixed_assets`、`total_assets` 分别对应哪些官方字段，是否为 `bs_cip`、`bs_net_fix_assets`、`bs_total_assets`？请说明单位、净额或合计口径，以及同一交易日的三个值是否取自同一报告期。
4. **历史财务取值**：历史回测按哪个公告日期或时间采用财务值？如何处理补充公告、修订和同一季度的多条记录，是否可能用到当时尚未公布的信息？这些规则与 `get_fina_reports` 是否一致，`date`、`is_latest`、`if_adjusted` 分别如何影响历史取值？

## 二、可选的导出与追溯能力

对于已完成的回测，是否有免费的只读方式：

- 查看或导出逐日参与计算的股票、输入数据，以及财务值对应的报告期和公告日期？
- 查询该次回测使用的数据版本、计算环境版本或其他可供复核的记录？

如不支持上述能力，请说明现有的替代核验方式即可。

如有说明文档或小样例，请提供链接。若相关能力需付费，请仅告知费用和权限，本次不申请订阅或新增回测。谢谢！
