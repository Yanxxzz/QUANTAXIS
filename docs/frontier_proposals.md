# 量价前沿探索与免费提案对照

量价研究员负责前沿探索：优先提出可观察状态、非对称、先后顺序或交互带来的独特经济预测。低先验置信度不妨碍提出假说；改名、调参数或堆算子不算新机制。不要求提案前已有好看的收益，但必须说明最接近的历史机制、最强竞争解释和最便宜的区分试验。基本面研究员保留经营变化与资本配置方向，独立证伪和来源门槛不变。

## 对照边界

两轮各由量价与基本面独立提案，再按原宿主执行挑战、答辩、设计审查及适用的跨审。第二轮可以利用第一轮已提交的经验；同轮初始提案互不可见。比较的是机制覆盖和提案质量，不是研究风格对收益的因果效应；两方向的数据条件不同，不据此排列研究员能力。

先冻结同一评分规则，再看输出。提案允许声明未通过原生验证的公式作为精确纸面定义；解析成功不代表算子、字段或数据已获原生验证。禁止为了评分编造数值、公告时点、PIT、收益或已执行测试。

- **机制差异**：审查员提取因果通道、状态/交互及有方向的预测，与本轮同侪、上一轮及已提供历史任务比较。必须给出最近邻任务和实际差异；名称、字段重合率只是辅助。
- **重复率**：报告精确公式重复数和经审查判断的机制重复数，分母为实际有效提案数。重复须绑定既有任务编号和理由；四份提案的小样本不作显著性推断。
- **可检验性**：五个二值检查分别为固定定义/有效域、输入与可用时点约定、可区分的控制、预先可判定的证伪规则、具体免费检验步骤。每项都要证据/缺口说明。另列免费数据就绪情况，不把“有检验计划”算作“已经可运行”，也不因财务PIT未过否定纸面可检验性。

每份实际 `review` 可附 `proposal_audit`：`causal_channel`、`state_or_interaction`、`prediction`、`nearest_task_id`、`mechanism_difference`、`distinct_mechanism`、`duplicate_task_ids`、`duplicate_reason`、`testability`、`testability_evidence`、`free_data_ready`、`source_gaps`。`testability` 的五个布尔键固定为 `fixed_definition_and_domain`、`inputs_and_clock`、`discriminating_control`、`falsification_rule`、`free_test_plan`。审查员的语义判断与协调者的确定性计数分开报告。

设计批准只代表局部纸面设计可以继续检查，不能作为来源、经济或入池通过。免费对照由 Lead 在完成设计处置后 park；不冻结官网派发，不激活 grant、不动正式因子池。新定义按原科学登记规则计数，原有失败不覆盖。

## 上下文精简

新 `workers.json` 可选 `"prompt_format": "lossless_refs_v1"`，在部署清单中冻结。原配置缺省 `full`，旧模型待办、工作包、哈希、模型会话和截止不改写。精简只发生在提示渲染：超过阈值的完全相同 JSON 值只保留一份，其余用 `$panda_same_as` 和 JSON Pointer 引用。每个引用可还原为完整原值，失败记录、资格编号/修订、证据绑定、退役和封存约束不删、不摘要。

源数据出现同名标记键或去重不能缩小时回退完整格式。提示说明前向引用及 `~1`/`~0` 转义，模型仍须返回原输出契约，不能把引用当成新增权限。离线全还原只证明传输等价；还须用真实模型交接检查可读性、隔离和有效回复，字节下降不冒充 token、费用或模型质量同比下降。

## 心跳延迟与有限恢复

本次真实运行发现：父宿主仍存活时，机器调度停顿会让全部子组件同时把旧心跳误认为孤儿信号，正常退出又耗尽重启次数。`active` 在心跳过期时增加原 supervisor 的进程出生身份核验；明确停止或原硬截止仍立即失效，真正父进程退出、PID 被复用或父状态已暂停时仍停止。

已耗尽的旧重启预算不清零。必要修复使用有界接续阶段，保留原包、未完成尝试、已提交提案及四个模型线程；旧阶段保持终止。接续从原任务阶段继续，总动作、原截止及总启动次数共同累计，不通过重新生成提案回避失败。
