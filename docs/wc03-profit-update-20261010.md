## 定义与流程

沿用形成日 2025-08-14—2026-08-26、持有日 2025-08-15—2026-09-03，51个五日调仓周期、10组、方向1。原2023扩展仍保持取消状态。

在新数值/标签计算前登记两个定义，累计研究数 468 → 470：

```
Q = (最新同版本期营业收入 - 本期营业成本) / 本期营业收入
    - (同版上年同期营业收入 - 上年同期营业成本) / 上年同期营业收入

GM01 = 行业内百分位(年度ARINV) × 行业内百分位(Q)
GM更新单独对照 = 行业内百分位(Q)
```

只支持 FY 年报和 H1 半年报，各自与同版上年同跨度比较。没有Q1/Q3完整报表，名称不能称全季度更新。比率避免半年/全年流量机械尺度差，但季节性及业务结构差异仍存在。它衡量利润率变化，不能解释成现金回收。利润质量研究仅提供机制背景，不证明这个本地同比变化定义有效。[NBER毛利盈利能力研究](https://www.nber.org/papers/w15940)。

执行顺序为冻结定义及对照、核对来源与形成时点、同样本信息检验、满足预设筛查时再准备财富回放。完整族BH、成本后净日Sharpe、实际因子池信号增量和盲样本尚未认证。本轮两个定义未通过信息筛查，因此没有新的净收益、净Sharpe或官网积分提升数据。
